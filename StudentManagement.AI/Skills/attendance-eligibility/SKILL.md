# Attendance Eligibility

Use this skill when a user asks whether a student is eligible to sit an examination based on attendance.

## Process

1. Identify the exact student before making an eligibility decision.

2. Retrieve the student's current attendance information using the available attendance tools.

3. Retrieve the relevant institutional attendance policy using the institutional knowledge search tool.

4. Do not assume an attendance threshold from general knowledge.

5. Compare the student's actual attendance percentage with the threshold retrieved from institutional policy.

6. If either the student's attendance data or institutional policy cannot be retrieved, explain that eligibility cannot be determined reliably.

7. Clearly explain:
   - the student's attendance percentage,
   - the required attendance percentage,
   - and whether the student meets the requirement.

8. Never modify attendance records while determining eligibility.
